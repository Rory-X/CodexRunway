颜色规则（由 Presentation 层决定，非 XAML 硬编码）

  • 蓝点 + 高亮底：当前 Codex 正在使用
  • 黄色：用量 ≥ 80%，快用完
  • 红色：凭据失效／需重新授权
  • 灰字：plan、邮箱、脱敏 key

与 macOS 的对应

  • 菜单栏图标 → 托盘图标（右键菜单待做）
  • NSPopover → 无边框浮窗，点外部/Esc 关闭
  • 状态栏绘制 → NotifyIcon + 生成的位图

关于密钥

  • API key 只保留前 4 位，其余打点
  • 短于 8 位整体打点（保留 4 位等于没脱敏）
  • 这一层有 12 个测试专门验证不泄漏
